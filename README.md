## Solution Documentation

### 1. Diagonal Difference

Calculates the absolute difference between the sums of the two diagonals of a square matrix.

**Complexity:**

* Time: O(N)
* Space: O(1)

### 2. Dynamic Array

Processes queries on a collection of sequences using the required sequence-selection and XOR logic.

**Complexity:**

* Time: O(N + Q)
* Space: O(N)

### 3. Time Conversion

Converts a 12-hour AM/PM time format into 24-hour format.

**Complexity:**

* Time: O(1)
* Space: O(1)

### 4. Sparse Arrays

Counts how many times each query string occurs in the given collection of strings.

**Complexity:**

* Time: O(N + Q)
* Space: O(N)

### 5. Compare the Triplets

Compares the scores of two participants across three categories and calculates their respective points.

**Complexity:**

* Time: O(1)
* Space: O(1)
